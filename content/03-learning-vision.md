## M3：机器学习最小完整实验（D9–D11）

先修：能写 Python 函数、读 CSV、理解数组 shape。目标：明白“从数据拟合模型，再对未参与拟合的数据评价”的流程，能够识别数据泄漏。

主线资料：R08 的线性回归、模型选择／过拟合；R09 的 estimator、preprocessing、Pipeline、model evaluation。复习矩阵乘法、均值／方差、导数／梯度、概率与条件概率；够用即可，不先补一整学期数学。

**任务一，D9**：生成带噪声的 `y=2x+1` 数据，拟合一条直线，画拟合图和残差图，比较估计参数与生成参数。说明噪声存在时为什么不要求每个点都落在直线上。

**任务二，D10–D11**：使用 `sklearn.datasets.load_digits()`，无需另下载数据集。它是小规模 8×8 手写数字数据，适合普通 CPU。固定种子 42，分层划分 train/val/test=60/20/20，保存每个 split 的样本索引，以便 MLP／CNN 共用。

建 `DummyClassifier` 多数类基线和 `StandardScaler → LogisticRegression` 的 Pipeline；缩放器只能在训练集拟合。先在训练集 fit，再在验证集比较至多 2 个参数设置；选定设置并冻结后只报告一次测试集结果。测试集不参加“反复换参数直到满意”。

提交 `split.json`、配置、混淆矩阵、准确率、5 个错误样例与原始结果。准确率 0.90 可作诊断参考，**不作唯一评分线**；若明显偏低，应检查数据／标签、划分、收敛警告及预处理。不得删掉错误样本以提高分数。

核心口述：分类与回归有什么区别？为什么训练精度高不一定泛化好？标准化为什么不能用整个数据集先拟合？标签不平衡时只看 accuracy 有何问题？

选做：比较决策树，观察深度变化；这不替代核心数据流程。

## M4：亲手训练神经网络（D12–D15）

主线读 R07 Learn the Basics 中 tensor、autograd、Dataset/DataLoader、Build Model、Optimization、Save/Load；R08 只挑 MLP 与过拟合部分。先照官方示例理解，再改为本课程 digits 数据；不要求抄完整教程。

### 模型与训练预算

- 输入 64 维，MLP 为 `64 → 64 → 10`，中间 ReLU；输出 logits，不提前 softmax 再交给 `CrossEntropyLoss`。
- 像素除以 16 做固定尺度变换；若学习额外预处理参数，只能在训练集估计。
- batch size 64，CPU，先跑 2 个 batch 的 smoke test，再最多 20 epoch。单次完整训练预算不超过 10 分钟；超时先减少 epoch 并记录硬件与实际时长。
- 日志包含 seed、epoch、train_loss、val_loss、val_accuracy；只用验证集选择 checkpoint。测试集留到配置冻结之后。

D12 写网络并打印 `batch×64 → batch×64 → batch×10`；计算 `f(x)=x²` 在 x=3 的梯度并与 autograd 对照。D13 写训练循环，说明 `zero_grad → forward → loss → backward → step`，保存 checkpoint，建立独立 `predict.py`。D15 只改变学习率，比较两次验证曲线并解释现象。

推理要 `model.eval()` 与 `torch.no_grad()`；说明 eval 控制某些层的行为，no_grad 控制梯度记录，两者不是同一个开关。checkpoint 至少记录模型参数、模型结构所需配置及预处理规则；恢复训练另需 optimizer 等状态，本月可选做。

**A4 交付**：训练命令、推理命令、配置、环境记录、逐轮 CSV、曲线、权重位置、最终测试结果。现场从新 Python 进程加载模型，输入一张已知测试图输出类别；不能以 Notebook 内存里已有的模型冒充成功加载。

选做 Fashion-MNIST：先用 5,000 张训练样本、1,000 张验证样本跑 3 epoch；数据需要联网缓存。只与相同数据划分的同类模型比较，不和 digits 指标混在一张“性能排名”里。

## M5：视觉与机器人观测（D16–D18）

本模块有两条小任务：理解可解释的图像处理，以及理解 CNN 的输入与计算。不要在 3 天内额外训练大型检测模型。

### 任务 V1：彩色目标定位

读 R10 的图像读写、颜色空间、阈值、轮廓。自己生成或用绘图工具绘制 10 张 320×240 的圆点图，记录真实中心坐标，其中 2 张不含目标。颜色、大小和位置变化即可，不需要下载真实机器人数据。

写脚本：读图 → BGR 转 HSV → 阈值 → 轮廓 → 最大有效目标的中心 → 保存带标记图与 CSV。无目标时输出 `valid=false`，不得保留上次中心充当本次检测。解释像素坐标的原点、横纵轴与宽高；像素坐标不能不经几何建模直接当作机器人世界坐标。

用 5 张图调阈值，另外 5 张作为保留测试。评价：有目标图的像素中心误差；无目标图的误检数。保留集上中心误差 ≤5 像素可作合成数据的参考目标，颜色或遮挡变化失败时保留失败证据。D18 额外加入暗光、近似背景色和遮挡样例，解释至少 3 种失败现象。

### 任务 V2：微型 CNN

用 A3 同一个 digits 划分，输入 `N×1×8×8`；建议 `Conv2d(1,8,3,padding=1) → ReLU → MaxPool2d(2) → Flatten → Linear(8×4×4,10)`。读 R08 的卷积、填充／步幅、通道、池化。训练不超过 20 epoch，使用与 MLP 相同的评价协议。

交每层输出 shape、参数量、训练时长和验证／测试指标。可以出现 CNN 不如 MLP 的结果；只要实验一致、原因分析合理就不扣“没超过前一个模型”的分。小数据上的一次成绩不代表架构普遍优劣。

**A5 现场**：给一张新图运行 V1；解释 RGB/BGR、NCHW；展示 V2 的加载和推理；说明从图像定位到实际机械臂动作还缺标定、坐标变换、状态估计与控制。

## 数据与实验共同规则

记录数据来源、代码版本、随机种子、切分索引和预处理。多次试验用验证集选方案；不要每次改代码都查看测试集。若必须修改最终方案，明确原测试集已被使用，并重新建立评价协议。小样本和单种子结论仅适用于本次练习，不能写成算法优越性的研究结论。

通过这三个模块意味着能开展小规模实验；距离目标检测、三维视觉、姿态估计、视觉语言模型仍有专项学习距离，结业后按毕设方向补。
