## 开课前准备

建议导师留出半天到一天做预演，时间不计入学生 95 小时。

- 收集学生系统、CPU 架构、内存、磁盘、GPU、编程背景和每周课程冲突；确定正式开课日，再把 D1–D30 映射到日历。
- 在一台普通 CPU Ubuntu／WSL2 上预演环境安装、digits 加载、小 MLP 训练、保存加载、ROS talker/listener 与 turtlesim。记录时长和实际包版本，发一套经过预演的环境文件。
- 至少准备一个可远程登录的 Ubuntu 24.04 备用环境；WSL 安装失败者先继续学习。远程账号、机器人和显卡工作站是否可用要明确，不默认存在。
- 准备资料备用入口与合法下载缓存；Python 包／数据缓存保留来源及版本。检索课程视频能否在学生网络播放；若不能，用配套讲义继续。
- 建立班级提交目录或内部 Git 平台，说明命名、截止时间、反馈方式；不要求学生将实验室数据发到公共代码平台。
- 建立助教答疑窗口，每周 2 次，每次约 30 分钟；同类环境问题集中解决。

## 开课诊断：D1 内 30 分钟完成

| 题目 | 预期证据 | 用途 |
|---|---|---|
| 用熟悉语言写函数，求列表正数均值并处理无正数 | 能运行的短代码 | 判断是否需要额外编程补课 |
| 说明 2×3 矩阵乘 3×1 的结果 shape | 2×1，并说明乘法含义 | 判断线代复习量 |
| 写出 x² 的导数，在 x=3 的值 | 2x、6 | 自动微分先修 |
| 解释训练样本全对但新样本差的可能原因 | 过拟合／分布变化等朴素认识 | 判断 ML 起点，不要求术语完美 |

若只有 Python 语法不熟但会其他语言，正常走主线。若连循环、函数都很生疏，用 D5–D8 与选做时间强化；严重欠缺时将毕业目标降为“完成环境、ML 小实验、ROS 通信”，并延长基础学习，不承诺相同 30 天达到全部终点。

## 三档工作量

| 档位 | 每个标准日 | 月总量 | 保留／调整 |
|---|---:|---:|---|
| 课程紧张 | 3 小时 | 26×3+4×1=82 小时 | 保留全部核心能力；给 CSV／训练／ROS 包骨架；减少自行搭框架和整理排版时间 |
| 标准 | 3.5 小时 | 95 小时 | 本 Wiki 默认任务量 |
| 学有余力 | 最多 4.5 小时 | 最多 121 小时 | 每周只加一个选做方向，不要求所有扩展都完成 |

82 小时版的具体调整：Linux 使用给定日志，学生写处理脚本；CSV 提供字段解析骨架；ML 提供 split 工具但学生解释并检查；训练提供主函数与 CLI，学生完成 forward／训练／加载；ROS 提供包目录与 entry_points，学生完成回调和闭环。GNN 保留手算与最小代码，Isaac Sim 仅阅读。评价仍看本人能否改代码与复现，不要求同样代码行数。

若学生连续两次因时间不足未通过，优先撤掉选做与额外架构工作；缓冲日只用于有限补漏。不要隐性把计划变成每天 8 小时。

## 每周你要检查什么

| 时间 | 导师最重要的问题 | 下周放行依据 |
|---|---|---|
| D4／D7 | 是否能独立进入环境、运行脚本、整理错误？ | A1；有问题者先配备用环境 |
| D8／D11 | 是自己理解 Python 和环境，还是照抄？是否数据泄漏？ | A2／A3 |
| D15／D18 | 是否真的完成保存加载？曲线与报告能对应吗？ | A4／A5 |
| D24 | 是否订阅反馈？停止条件是否真的运行？ | A6 |
| D26 | 是否知道高级平台的作用和依赖边界？ | A7 |
| D30 | 能否交给别人复跑？下一阶段缺口是否具体？ | A8 与毕设交接表 |

每周可做 20 分钟全体总结＋每人 5–10 分钟问题抽查；正式验收按课程节点进行，重叠的总结合并。若有 N 名学生，8 次每人 12 分钟的验收约为 1.6N 小时导师工作量；另加开课准备和集中答疑。超过 8–10 人时分小组演示，但每人保留独立代码解释与现场修改。

## 反馈与掉队处理

把问题分为环境阻塞、概念不懂、代码实现和时间不足。环境阻塞 45 分钟内报备，导师集中处理；概念不懂让学生用 3 行例子解释；代码实现让学生给最小复现；时间不足降低非核心范围。

建议红黄绿：绿＝必过项完成；黄＝已能跑但理解／记录不足；红＝无法运行或关键逻辑错误。黄安排下一缓冲日补验；红暂停后续依赖作业，先补前置。日期可以按班级实际顺延，但要写明是延期，不把跳过标成完成。

## AI 辅助与原创要求

允许询问概念、解释报错、生成样例和审查代码。学生在报告里写明用了哪些工具、哪些部分得到帮助、做了什么验证。现场允许查 API 文档；不允许把即时生成回答替代本人解释。判断标准是理解、修改和结果可信，不通过刻意禁止工具来增加负担。

## 基础月后的分方向衔接

| 毕设方向 | 优先补课 | 第一个应交的结果 |
|---|---|---|
| 视觉／感知 | 相机标定、三维几何、任务指标、目标数据集 | 固定数据集上的可复现基线与错误分析 |
| 图学习 | GCN/GAT、图任务、采样与评价协议 | 小数据集基线＋一项受控消融 |
| 机器人控制 | 运动学、坐标变换、规划、平台驱动 | 仿真中的目标动作与接口验证 |
| 模仿学习／VLA | episode 数据、动作表征、推理延迟、模型依赖 | 小段离线数据跑通预处理与策略推理 |
| Isaac／真机系统 | 具体平台版本、驱动／桥接、时钟、设备规范 | 支持平台上的传感器与指令闭环 |

后续学习量取决于具体课题，不能预设“基础月结束就能独立部署任意模型”。D30 由导师确认最终仓库、模型名称、硬件和实验目标，再安排下一个两周的专项计划。
