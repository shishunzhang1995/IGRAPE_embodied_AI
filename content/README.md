# 具身智能本科毕设基础训练营

**30 天 · 核心约 95 小时 · 普通笔记本优先 · 每 2–4 个学习日有可验收成果**

面向有大学数学和至少一种编程语言基础、但尚未建立 Linux／深度学习／机器人开发经验的大四本科生。按国防科大大四学生的学习能力设计，但不假定所有专业都已掌握 Python 或机器学习。编写与资料核对日期：2026-10-26。

这里将口述中的“巨生智能”理解为“具身智能”。具体最终模型名称尚未确认，因此以通用具身学习流程为主，openpi／LeRobot 作为后续方向入口，不默认某个型号、权重或机器人平台。

## 一个月结束时应达到什么水平

学生应能独立进入 Linux 工作环境，整理文件、运行脚本、查日志，使用 Git 管理代码；创建和复现 Python 环境；用一个小数据集完成训练／验证／测试，保存并加载模型；说明图像、张量、坐标系与 ROS 消息的关系；写一个 ROS 2 Python 节点，完成有反馈的仿真控制；读懂具身项目中 observation、action、episode、policy 的基本接口。

**这个月定位是“具备进入毕设课题的基础”，不是在 95 小时内掌握 Linux 运维、完整机器学习体系、机器人控制、强化学习和大模型训练。** GNN 要完成最小消息传递实验；Isaac Sim 要能判断部署条件、理解基本工作流；独立部署大型具身模型、完整 GNN 研究和真机实验放入后续专项阶段。

## 工作量约定

- 26 个标准学习日，每日 3.5 小时：资料 45 分钟、动手 120 分钟、整理 30 分钟、问答／机动 15 分钟。
- D7、D14、D21、D28 为缓冲日，每日最多 1 小时整理和补漏，其余时间休息或处理课程。
- 核心合计：26 × 3.5 + 4 × 1 = **95 小时**。验收、开课诊断和答辩已计入当天时长。
- 只够每天 3 小时者，采用导师手册中的 82 小时精简版；每天可投入 4–5 小时者，每个标准学习日最多增加 1 小时选做，约 121 小时封顶。
- 本周没通过核心验收时，先用选做时间和缓冲日补核心。不要用堆视频时长替代提交成果。

## 默认工具路线

| 用途 | 课程选择 | 边界 |
|---|---|---|
| Windows 上的 Linux | WSL2 + Ubuntu 24.04 LTS | 显式选版本，不跟随默认最新 Ubuntu |
| Linux 原生电脑 | Ubuntu 24.04 LTS | 已有可用环境不为课程反复重装 |
| Python／深度学习 | Linux 内 Miniconda，独立 `embodied-basics` 环境，Python 3.11，CPU PyTorch | Anaconda 已装在同一 Linux 内也可；Windows Anaconda 不等于 WSL 内安装 |
| ROS 2 | Ubuntu 24.04 + Jazzy，系统 Python | 不在 Conda 环境里安装／运行课程 ROS 节点 |
| 训练数据 | 首选 sklearn 自带 digits，选做 Fashion-MNIST | 无独显也能完成核心，不下载大型机器人数据集 |
| 轻量机器人练习 | turtlesim／无图形二维运动节点 | 学习闭环，不把乌龟仿真等同于物理仿真 |
| Isaac Sim | 导师预配置的受支持工作站 | 按具体版本官方要求检查硬件；不作为普通笔记本必装项 |

ROS 2 Jazzy 的 Ubuntu 二进制包对应 Ubuntu 24.04，具体安装以[官方安装页](https://docs.ros.org/en/jazzy/Installation/Ubuntu-Install-Debs.html)为准。Isaac Sim 各版本有独立的硬件、驱动要求，见[版本化要求页](https://docs.isaacsim.omniverse.nvidia.com/5.1.0/installation/requirements.html)。这些是本课程的兼容性选择，不是“所有最新软件”的组合。

## 一个贯穿全月的仓库

每名学生维护一个 `embodied-foundations-姓名` 仓库，依次添加 `linux/`、`python/`、`ml/`、`vision/`、`ros_ws/src/`、`gnn/`、`final/`、`reports/`。可使用实验室内部 Git 平台，也可仅本地 Git 加打包提交；公开上传不是要求。数据缓存、模型权重、ROS build/install/log 不提交 Git。

每次验收交代码、运行命令、环境版本、原始结果及一页解释。允许使用 AI 辅助，但须记录用途，能现场解释、修改和重新运行自己的代码。

## 使用与维护

这是一套可直接分发的 Markdown Wiki，复制整个目录即可保留页面之间的链接；在支持 Markdown 的编辑器、Git 仓库或实验室 Wiki 中阅读。未部署到公网。教学任务为本方案原创，知识学习通过链接到原作者资源完成；无需购买课程，也不要求通读整本书。

资料链接已做在线检索或页面核对；ROS 官方站对自动访问有防护，已通过官方 Jazzy 文档源码核对关键兼容性，页面仍建议在普通浏览器复核。B 站播放器有访问限制，未逐个验证视频播放。资源页已注明限制。课程命令是教学配方，本次未在学生设备上执行；开课前请导师按执行手册做一次环境预演。

交付检查：日程与模块工时均为 95 小时，验收权重合计 100%；8 个阶段均给出资料范围、任务、提交物与必过项；高级方向有时间与硬件边界。当前工具环境未能启动本地命令执行进程，因此没有生成压缩包或声称完成命令实跑；Markdown 文件可直接复制分发。
